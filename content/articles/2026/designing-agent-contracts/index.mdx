这是一篇仍在打磨中的草稿：只应在开发环境可见，生产构建会被过滤。

做后端时我们习惯用接口契约约束上下游。做 Agent 时同样的问题回来了：如果每个 Agent 的输入输出都是自由文本，编排层就无从校验。用 schema 把边界钉死，才谈得上可靠的多 Agent 协作。
