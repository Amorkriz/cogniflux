## 背景

在 Flux Agent Runtime 的早期版本里，一次多轮推理往往要等好几秒才「啪」地吐出全部结果。总耗时其实不算离谱，但等待过程完全是黑箱——这正是后端做同步接口时最熟悉的那种焦虑。

## 做法

把网关的返回从单响应改成事件流：`start → delta* → done`，让 UI 拿到第一个 `delta` 就开始渲染。

```ts
for await (const event of stream) {
  if (event.type === "delta") append(event.text);
}
```

## 结论

总耗时几乎没变，但「开始有反馈」的时间点提前了一个数量级，体感完全不同。假设成立。
