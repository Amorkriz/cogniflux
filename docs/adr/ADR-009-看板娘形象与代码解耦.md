# ADR-009 看板娘形象与代码解耦：双契约 + 纯资产替换

- 状态：已采纳（2026-07）
- 相关：[ADR-006](./ADR-006-动效架构.md)、[ADR-008](./ADR-008-Agent安全边界.md)、docs/COMPANION.md、ARCHITECTURE.md §8

## 背景

AIGC 定制看板娘形象是本次视觉改版的核心诉求，且形象迭代频率预期**高于代码迭代**（换风格、换季节皮肤、换角色）。若形象与组件代码耦合，每次换形象都变成一次工程活动（改代码→评审→回归）；必须把"换形象"从工程活动降级为**资产替换活动**。

## 决策

- **形象 = 纯资产**：静态立绘 `public/companion/poster.webp` 与动态模型 `public/companion/companion.riv`，均不进 `src/`。
- 代码只依赖**双契约**：
  - **契约 A（资产路径）**：固定路径 `public/companion/{poster.webp, companion.riv}`，运行时探测 `.riv` 存在则点亮 Rive 模式，否则回退静态立绘。
  - **契约 B（状态机命名）**：State Machine 名固定 `Companion`，五状态 `idle/greeting/listening/thinking/speaking`，唯一真值源为 `src/services/companion/types.ts` 的 `COMPANION_STATES`，由 `tests/services/companion.test.ts` 契约快照守护。
- 结果：**更换形象零代码改动**——覆盖资产文件即完成换肤，删除 `.riv` 即回退，三条更换路径见 docs/COMPANION.md §3。

## 备选与否决

- **manifest.json 多角色配置体系**：预防性抽象、违反"两次规则"——当前只有一个形象，首次真实换肤后再评估是否需要配置化。
- **形象内联进组件**（import 图片 / 内嵌 base64）：形象与代码耦合，换肤即改代码，与核心诉求直接冲突。
- **CDN 独立托管资产**：静态站一体部署（构建产物含 `public/`）已够用，未触发独立托管条件（体积/带宽）。
- **Live2D 路线**：运行时重（SDK 体积远超预算）+ 制作链路重（专业建模工具），与"AIGC 生成图 → 快速上线"的定制流程冲突；Rive 的图层导入 + 状态机模型更匹配。

## 后果

- 契约 B 成为 Rive 制作侧的**硬约束**：模型作者必须按 `COMPANION_STATES` 命名状态机与状态，契约快照测试在 CI 中守护，改名 = 测试失败。
- 频繁换肤需关注 **HTTP 缓存失效**：资产文件名不变，部署后需强刷/版本 query/等 `max-age` 过期（见 docs/COMPANION.md §4）。
- 双形态回退保证资产缺失不致错：`.riv` 缺失或加载失败静默回退 `poster.webp`。

## 重新评估条件

首次真实换肤后评估 manifest 配置体系（多角色/多皮肤切换）；若资产体积或带宽成为瓶颈，评估 CDN 独立托管；若 Rive 表达力不足（需物理骨骼/口型同步），再评估其他运行时。
